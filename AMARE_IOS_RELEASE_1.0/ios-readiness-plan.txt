RECOMMENDED BUNDLE ID

(Match Android applicationId and capacitor.config.ts appId)

STEPS TO ADD iOS (when Mac + enrollment ready — NOT NOW)
--------------------------------------------------------
1. npm install @capacitor/ios@^7.6.8
2. npx cap add ios
3. npm run build (or future build:ios-release script)
4. npx cap sync ios
5. Open ios/App/App.xcworkspace in Xcode
6. Set Team, Bundle ID com.amarewellness.app, Automatic signing
7. Portrait only: UISupportedInterfaceOrientations = UIInterfaceOrientationPortrait
8. Launch screen background #faf3eb (match Android splash)
9. Add AppIcon asset catalog + 1024x1024 for App Store Connect
10. Push capability + GoogleService-Info.plist (when push enabled)
11. Archive → Distribute → App Store Connect / TestFlight

XCODE / SIGNING
---------------
- Apple Developer Program membership (Organization recommended)
- Distribution certificate + App Store provisioning profile
- Push Notifications capability (when push enabled)
- No Sign in with Apple capability needed for current auth model
- macOS required — cannot sign .ipa from Windows alone

APPLE DEVELOPER ACCOUNT
-----------------------
Organization enrollment:
  - D-U-N-S required (same as Google Play Organization)
  - Legal entity name must match D&B record
  - Public website on org domain (amarewellness.com)
Individual enrollment:
  - No D-U-N-S
  - Seller name = personal legal name (not recommended for studio brand)
