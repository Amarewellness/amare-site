# מוצרים — כפתור רכישה וקישורי צ׳קאוט

מסמך זה משמש להחזיר את חוויית הרכישה באתר כשיהיו קישורים עדכניים (בלי Wix).

## איפה מופיע כפתור “Add to cart”

1. **`scripts/build.mjs`**
   - קבוע עליון: `SHOW_PRODUCT_PURCHASE_BUTTONS` (כרגע `false`).
   - כשמגדירים `true`, הבנייה מוסיפה שוב את הבלוק עם המחלקה **`shop-product__actions`** בתוך הפונקציה **`renderProductMain`** — כפתור עם טקסט *Add to cart on the AMARÉ store* ו־`href` מתוך **`product.wixUrl`** לכל פריט במערך **`PRODUCTS`**.
   - לפני הפעלה: לעדכן את השדה **`wixUrl`** לכל מוצר לכתובת החנות הסופית (או לשנות את תבנית הכפתור אם צריך טקסט/זרימה אחרים).

2. **הערת רשת במוצרים (`products.html`)**
   - בתוך **`renderProductGrid`**, כש־`SHOW_PRODUCT_PURCHASE_BUTTONS === false`, מוצגת שורת **`shop-grid__note`** ניטרלית (“Browse each style…”).
   - כש־`true`, חוזרת השורה עם קישור לקטלוג הישן והזכרת Wix — רק אחרי שיש החלטה מוצדקת להחזיר ניסוח זה.

3. **טקסטים סטטיים ב־`src/content/products.html`**
   - פסקאות ההיכרות והמשנה בתחתית עודכנו כדי לא להבטיח צ׳קאוט אונליין בזמן שהכפתורים מוסתרים.
   - אחרי הפעלת הרכישה, כדאי לעבור על הניסוח שוב כדי שיתאים למציאות החנות החדשה.

## הפעלה מהירה (צ׳קליסט)

1. להחליף את כתובות **`wixUrl`** במערך **`PRODUCTS`** ב־`scripts/build.mjs` לקישורי החנות החדשים (שם השדה יכול להישאר עד ריפקטור עתידי).
2. להגדיר **`SHOW_PRODUCT_PURCHASE_BUTTONS = true`** באותו קובץ.
3. להריץ **`npm run build`** ולבדוק דף **`/products.html`** ודף מוצר לדוגמה תחת **`/product/…`**.
4. לעדכן את **`src/content/products.html`** אם רוצים להזכיר במפורש צ׳קאוט אונליין אחרי החיבור.

## סיכום שינויי ממשק (מצטבר)

תיעוד לא רשמי של מה שנגע לממשק המשתמש בפרויקט (כולל עדכונים על דפי טיפולים, ביקור ראשון וחנות).

### דף Treatment room rental (`treatment-room.html` + JS/CSS)

- בוחר יום בשבוע עם דיאלוג רב־שלבי (יום → משך יום מלא/חצי → חלון חצי יום בוקר/ערב כשנדרש).
- פאנל תמחור אחרי בחירה מלאה: יום מלא / חצי יום במחירים שהוגדרו, שדה חודשי התחייבות, סיכום טקסט לטופס (`pricing_summary`), שדות נסתרים למחיר משוער.
- גלריית תמונות מתיקיית `/images/treatment/` (כולל `6.webp` כשנוסף).
- התאמת גובה המודל כדי למנוע גלילה מיותרת ברשימת הימים.
- תיקון פריסת טופס (רוחב פיקר, תיבת סימון עם טקסט ארוך).
- פסקת מחיר מפוצלת לשורה ראשית + שורת Reference קטנה יותר.
- יום שישי: יום מלא וערב לא זמינים — מוצגים ככפתורים אפורים ולא פעילים (`disabled`).
- שבת ברשימה כלא זמין (אפור, לא ניתן לבחירה).
- הסרת שורת ההערה על שישי מתחת ל־Preferred weekday (נשאר הסבר בתוך המודל ובלוגיקה).
- תיבת סימון עם הבהרה שהגשת טופס אינה אישור והבקשה נבדקת לזמינות.
- טופס Netlify עם באנר + דיאלוג הצלחה כמו טפסים אחרים.

### דף First visit (`first-visit.html`)

- תוכן מלא בעברית הוזמנה באנגלית: פתיחה, לפני שיעור, ציוד (Reformer / Mat / Kangoo), הריון/פציעה + FAQ.
- סעיפים “Where we are” ו־“After class” עם כתובת, חניה והמשך אחרי שיעור.

### דפי מוצרים וקטלוג

- הוסר פסקת המשנה על צ׳קאוט Wix מתחת לכפתור הרכישה בכל דף מוצר (בנייה מתבנית ישנה ב־`build.mjs`).
- **כרגע:** כפתורי “Add to cart” מוסתרים באמצעות **`SHOW_PRODUCT_PURCHASE_BUTTONS`**; שורת הרשת בקטלוג והטקסט ב־`products.html` לא מפנות לצ׳קאוט Wix עד להפעלה מחדש.

### דף המחירון Mindbody (`/pricing`)

- הקטלוג נטען מ־Mindbody (**services** + חוזים לפי צורך) דרך API באתר; כפתורי **Subscribe** / **Buy** מנותבים בהתאם לדגל ב־**`src/js/pricing-api.js`**.
- **כרגע (Classic):** הדגל **`PRICING_MINDBODY_EXPRESS_CHECKOUT_ENABLED`** מוגדר **`false`** — לחיצה פותחת **מיד** קישור **Mindbody Classic** בטאב חדש (`studioid` + `stype` + `prodid`), ללא דיאלוג ביניים, כשהקישור נבנה מתוך שורות הקטלוג.
- **עתיד (EXPRESS בתוך האתר עם Mindbody):** שינוי הקבוע למעלה ל־**`true`** מחזיר את **דיאלוג הרכישה** עם OAuth, בדיקת ארנק (`/client/stored-cards`), dry-run והפעלות live לפי ההגדרות בשרת.
- **בר ההתחברות:** **`AUTH_MINDBODY_WALLET_PROBE_ENABLED`** ב־**`src/js/mindbody-auth.js`** — כעת **`false`**; אין טעינת badge לפי ארנק Mindbody, תוך שמירת הקוד למסלולי EXPRESS עתידיים (למשל Stripe).
- פירוט ארוך ובעיות טכניות נפוצות: **`docs/MINDBODY-CHECKOUT-OVERVIEW.md`**.
